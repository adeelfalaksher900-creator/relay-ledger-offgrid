# Contributing

Fork the repository, create a focused branch, install Node 22.12+ or 24.x and run `npm ci` and `npm run dev`.

Start with a clear user problem. Useful contributions include device compatibility, readable conflict review, explicit storage failures, independent causal-model tests and real-camera validation. Discuss large protocol or privacy changes in an issue first.

Run `npm test` and `npm run build`. For UI changes, exercise success, wrong password, malformed import, keyboard navigation, narrow width and offline reload. Include screenshots and honest limits. For merge changes, test commutativity, idempotence, preserved competing values and older snapshots after resolution. Keep synthetic scanner tests separate from physical camera claims.

A pull request should explain the problem, change, verification and remaining risk. Disclose AI assistance and understand the code. Do not commit credentials, real volunteer records, browser storage, dependency directories or generated video binaries. Original contributions use the project's MIT license; third-party code keeps its notices.
